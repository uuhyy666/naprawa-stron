Licznik pobrań darmowej lekcji udostępnianej z Facebooka

Odpowiedź na pytanie „czy da się to zrobić informatycznie” — wraz z gotowym kodem

Przygotowane 11.09.2026 przez bartekdev_pl na potrzeby zlecenia 143098

Najpierw zła wiadomość, bo od niej trzeba zacząć

Jeśli plik HTML jest wgrany bezpośrednio na Facebooka, liczby pobrań nie da się zmierzyć. Żadnym sposobem. Plik serwuje Facebook ze swojego serwera, do jego logów nie ma Pan dostępu, a doklejenie licznika wewnątrz pliku niczego nie da: skrypt uruchomi się dopiero wtedy, gdy ktoś otworzy plik u siebie, a nie w chwili pobrania. Część osób pobierze i nigdy nie otworzy — te pobrania znikną.

Każdy, kto obiecuje „doklejenie licznika do pliku na Facebooku”, albo nie zrozumiał zadania, albo policzy Panu coś innego, niż Pan myśli.

Dobra wiadomość: wystarczy odwrócić kolejność

Zamiast wrzucać plik na Facebooka, wrzuca Pan link. Link prowadzi do adresu, który Pan kontroluje — ten adres zapisuje pobranie i natychmiast przekazuje użytkownika do pliku. Dla odbiorcy różnica jest żadna: klika i pobiera. Dla Pana różnica jest taka, że każde kliknięcie zostaje policzone.

Jak to wygląda dla użytkownika

Darmowa lekcja 1 — kurs angielskiego

Plik HTML, otwiera się w przeglądarce, bez instalowania czegokolwiek

0

pobrań (demo — liczy tylko w tej przeglądarce)

Powyżej to makieta pokazująca zachowanie. W wersji działającej licznik rośnie po stronie serwera, więc widzi Pan pobrania wszystkich osób, a nie tylko swoje. Licznik na stronie można zresztą ukryć — liczba może trafiać wyłącznie do Pana arkusza.

Gotowy kod — Google Apps Script

Do wklejenia w script.google.com, publikowany jako aplikacja internetowa dostępna dla wszystkich. Zapisuje pobranie do arkusza i od razu przekierowuje do pliku.

// Licznik pobrań — zapisuje wiersz w arkuszu i przekierowuje do pliku.
// Wklej w script.google.com, ustaw dwie stałe niżej, opublikuj jako aplikację internetową
// („Wykonaj jako: ja”, „Kto ma dostęp: wszyscy”). Otrzymany adres wklejasz na Facebooka.

const ID_ARKUSZA = 'TU_WKLEJ_ID_ARKUSZA';   // z adresu arkusza, między /d/ a /edit
const ADRES_PLIKU = 'TU_WKLEJ_LINK_DO_PLIKU'; // np. bezpośredni link z Dysku Google

function doGet(e) {
  try {
    const arkusz = SpreadsheetApp.openById(ID_ARKUSZA).getSheets()[0];
    if (arkusz.getLastRow() === 0) {
      arkusz.appendRow(['Data i godzina', 'Lekcja', 'Źródło']);
    }
    const parametry = (e && e.parameter) || {};
    arkusz.appendRow([
      new Date(),
      parametry.lekcja || '1',           // ?lekcja=2 rozróżni kolejne lekcje
      parametry.zrodlo || 'facebook'     // ?zrodlo=grupa-xyz rozróżni miejsca publikacji
    ]);
  } catch (blad) {
    // Gdy zapis się nie uda, użytkownik i tak ma dostać plik.
    // Nieudany zapis nie może blokować pobrania — to byłoby gorsze niż brak licznika.
    console.error(blad);
  }
  return HtmlService.createHtmlOutput(
    '<meta http-equiv="refresh" content="0; url=' + ADRES_PLIKU + '">' +
    '<p>Pobieranie rozpocznie się za chwilę. Jeśli nic się nie dzieje, ' +
    '<a href="' + ADRES_PLIKU + '">kliknij tutaj</a>.</p>'
  );
}

Co Pan z tego ma

  • Arkusz, w którym każde pobranie to jeden wiersz z datą i godziną — widać nie tylko ile, ale i kiedy.
  • Parametr ?lekcja=2 pozwala liczyć osobno każdą lekcję jednym i tym samym skryptem.
  • Parametr ?zrodlo= pozwala sprawdzić, który post czy która grupa przynosi pobrania.
  • Gdy zapis do arkusza się nie powiedzie, użytkownik i tak dostaje plik. Licznik nie może psuć pobierania.

Czego tu nie ma i czego nie sprawdziłem

  • Nie uruchomiłem tego skryptu na Pana koncie — nie mam do niego dostępu i nie chcę mieć. Kod jest krótki właśnie po to, żeby dało się go przeczytać przed wklejeniem.
  • Nie policzy osób, które pobrały plik wcześniej, przed wdrożeniem licznika. Liczenie zaczyna się od dnia uruchomienia.
  • Nie odróżni jednej osoby pobierającej trzy razy od trzech różnych osób. Można to przybliżyć, ale uczciwiej jest powiedzieć, że to liczba pobrań, a nie liczba osób.
  • Nie wie, czy ktoś lekcję przeczytał. Mierzy zainteresowanie na wejściu — o to Pan pytał — a nie ukończenie.
